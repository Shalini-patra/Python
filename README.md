## 📂 Current Files

### `01_basic_web_request.py`

Learn how Python connects to a website using the `requests` library.

Topics:

* GET requests
* HTTP responses
* Status codes
* HTML response
* `response.text`

### `02_http_status_codes.py`

Understand common HTTP status codes and how they affect web scraping.

Topics:

* `200` — Success
* `301` / `302` — Redirects
* `403` — Forbidden
* `404` — Not Found
* `429` — Too Many Requests
* `500` — Server Error

## ⚠️ Responsible Scraping

This repository is for learning purposes.

When scraping real websites:

* Respect the website's Terms of Service.
* Check `robots.txt`.
* Respect rate limits.
* Avoid excessive requests.
* Do not bypass authentication or anti-bot systems.
* Prefer official APIs when available.
* Do not collect private or sensitive information.
